# LLM Evaluation

**PENDING HUMAN REVIEW**

The automated `schema-only` mode verifies prompt construction, input delimiting, sanitization, and output constraints across 20 synthetic cases. It is not a Qwen quality evaluation.

No live Qwen score is published until every saved live output has two independent human reviews with model version, prompt version, and timestamp. Scores must be computed from the completed CSV; Qwen is not used as its own reviewer.

See the relative [rubric](../datasets/llm/rubric.md) and [review template](../datasets/llm/human_review_template.csv).
