# Sample Job Descriptions for Match & ATS Testing

Use these pre-tested job descriptions in the **Job Match & ATS** tab of the Resume Analyzer.

---

### JD 1: Senior Data Scientist (Target: 100% match with `01_data_science_senior.pdf`)
```
We are seeking an experienced Senior Data Scientist to lead our machine learning and AI initiative. 
The ideal candidate will have strong expertise in Python, SQL, Pandas, NumPy, Scikit-learn, and PyTorch or TensorFlow. 
You will architect predictive models, build end-to-end data pipelines with Docker, and deploy models on cloud infrastructure like AWS. 
Must possess strong communication skills, experience with Tableau reporting, and a passion for data-driven innovation.
```

### JD 2: Senior Frontend / Fullstack Engineer (Target: 90%+ match with `02_web_developer_mid.pdf`)
```
We are looking for a skilled Web Developer / Frontend Engineer proficient in JavaScript, TypeScript, React, and Node.js.
Requirements include experience building responsive interfaces with HTML, CSS, TailwindCSS, and Next.js, as well as developing RESTful APIs with Express and PostgreSQL.
Experience with Docker, Jest testing, and Git version control is essential for this role.
```

---

### JD 3: Native Android Mobile Engineer (Target: 85%+ match with `03_android_developer.pdf`)
```
Our mobile team is hiring a dedicated Android Developer with deep expertise in Kotlin, Java, and the Android SDK.
Must be experienced with modern UI development using Jetpack Compose, asynchronous flows with Coroutines, local caching with Room database, and network calls via Retrofit.
Familiarity with MVVM clean architecture, Dagger-Hilt dependency injection, and Firebase integration is required.
```

### JD 4: Product & UI/UX Designer (Target: 90%+ match with `05_ui_ux_designer.pdf`)
```
We are searching for a creative UI/UX Product Designer with hands-on expertise in Figma, Adobe XD, Wireframing, and Prototyping.
You will conduct User Research, synthesize Usability Testing results, and maintain our cross-platform Design Systems.
Basic understanding of frontend HTML and CSS principles is a plus.
```

### JD 5: Senior DevOps / Cloud Architect (Target: 0% match / Gaps test with any developer resume)
```
We require a Senior Cloud Infrastructure and DevOps Architect with 7+ years of experience in Kubernetes, Terraform, Ansible, Helm, Prometheus, Grafana, and CI/CD pipeline automation on Google Cloud Platform and Azure.
Must hold CKA (Certified Kubernetes Administrator) and expert-level Linux kernel tuning experience.
```
